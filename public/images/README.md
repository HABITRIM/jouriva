# /public/images/

## Phase 1 disclosure — placeholder photography

All images in this folder are **AI-generated placeholders** created during
Phase 1 to exercise the responsive-image pipeline (`next/image`, aspect
ratios, `sizes`, priority hints) and to demonstrate the layout system.

They are **not final editorial photography**. Before production launch:

1. Replace with licensed/owned photography (or a DAM/CDN in Phase 2+).
2. Keep `og-default.jpg` aligned with the final brand masters.
3. Update alt text in `src/content/*` — alt text architecture is per-locale.
